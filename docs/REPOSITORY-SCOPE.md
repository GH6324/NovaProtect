# 仓库范围说明

本仓库是 NovaProtect 的**公开部分**，不是完整产品源码。本文说明哪些内容公开、哪些属于专有实现，以及为什么这样划分。

## 公开内容

| 路径 | 内容 | 原因 |
| --- | --- | --- |
| `sdk/` | 集成头文件与示例 | 用户接入所必需；只含标记宏与用法，不含引擎实现 |
| `ui/` | WinUI 3 客户端 | 展示功能面与交互，便于评估与反馈 |
| `website/` | 官网 PHP 源码 + 部署脚本 | 已授权部署者需要自行安装与维护站点 |
| `installer/` | Inno Setup 脚本 | 说明安装布局与文件清单 |
| `tools/` | 发布工具（打包、校验、版本管理） | 说明发布流程与产物校验方式 |
| `build.ps1` | 构建入口 | 说明构建阶段划分；缺引擎源码时无法产出完整保护器 |
| `docs/` | 产品说明、部署文档、验证报告 | 对外可验证的能力声明 |

## 不公开内容（专有实现）

以下组件构成产品的核心竞争壁垒，**不在本仓库内**：

- **VM 指令集与线格式**：逻辑操作码定义、操作数编码表、指令长度/分支/标志判定。
- **字节码解释器**：运行时 x64 解释器、guest 分派、寄存器重映射。
- **二次虚拟化**：阶段切分、嵌套层级提升、每层独立密钥与操作码置换。
- **加密层**：字节码密钥流、区域密钥派生。
- **PE 变换与打包器**：区域翻译、stub 生成、payload 组装、trampoline 布局。
- **变异与反调试内核**：指令变异模板、反调试/反虚拟机检测。
- **引导桩汇编**：x64/x86 入口桩、解包器。
- **内部逆向工具**：VM 调试器、运行时检查器、内存转储等。

这些内容对应工作区中的 `src/`、`include/`、`runtime/`、`tests/`，以及 `tools/` 下的调试类工具，均被 `tools/package-github-source.ps1` 排除。

## 可构建性

本仓库**不能**独立构建出完整的 NovaProtect 保护器，因为缺少引擎源码。可独立使用的部分：

- **SDK 头文件**：直接复制进你的项目即可使用。
- **官网源码**：可在自有服务器上完整部署与运行。

客户端的 UI 与安装器脚本可阅读，但构建它们需要引擎产出的运行时 blob。

## 安全设计

裁剪由 `tools/package-github-source.ps1` 强制执行，不是手工约定：

- `$coreDirs` 列出整目录排除的核心目录；
- `$forbidden` 断言核心文件**确实不在**包里（不是"未列出"），一旦有人改动排除规则导致泄漏，打包会直接失败；
- `$banned` 拦截签名私钥、商业 SDK 二进制等敏感路径；
- 生成的 `include/vmp_markers.h` 是公开占位版本，只保留稳定的标记字节模式，不含引擎引用。

## 版本

客户端与官网版本独立递增。当前版本以 `VERSION` 与 `website/VERSION` 为准，安装包的 SHA-256 以 `website/release.json` 为准（由发布流程自动写入）。
