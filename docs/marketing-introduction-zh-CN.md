**NovaProtect｜让关键代码更难被读懂，让软件保护更容易管理**

NovaProtect 是面向 Windows EXE 的代码保护工作台，为软件开发者提供从目标分析、保护配置到构建输出的一体化操作体验。产品结合区段保护、局部代码虚拟化、VM 前置代码变异、导入保护与运行时校验，围绕商业软件中的核心算法与关键业务逻辑，提供可配置的保护流程。

客户端可识别和处理 C/C++、Rust、Go 等工具链生成的受支持原生 EXE，并为 C#、VB .NET EXE 提供兼容 CLR 的加密封装。具体能力依据文件格式、处理器架构和代码区域确定，构建前即可查看实际生效的保护项目。

**加密与保护原理：从文件结构到关键代码，分层处理**

NovaProtect 的保护流程从分析目标文件开始：识别 PE/CLR 格式、处理器架构、区段结构和 SDK 标记，再按目标能力生成构建计划。

- **区段保护**：对符合条件的原生代码区段以及可选资源区段进行打包，按压缩收益选择是否压缩，并在启用加密时采用 XOR 编码。程序启动后，由对应架构的加载器完成恢复。
- **关键区域虚拟化**：针对原生 x64 程序中由 NovaProtect SDK 标记、且能够成功翻译的代码区域，将机器指令转换为内部虚拟指令，由内置解释器执行，增加直接理解原有逻辑所需的分析工作。
- **字节码组合加密**：对生成的 VM 字节码采用 RC4、XOR 与字节加法组合处理，并结合区域随机参数及指令编码映射，改变代码在输出文件中的表现形式。
- **变异与导入保护**：Ultra 管线可在虚拟化前进行代码变异，并对适用的字节码追加混淆；导入保护通过保存导入信息、在运行时重建导入地址表，改变常规静态导入结构。
- **运行时校验**：按目标架构和配置执行载荷或代码区域完整性校验；原生 x64 还提供运行时许可数据校验与机器标识绑定。
- **.NET 加密封装**：对受支持的托管 EXE 使用基于 XTEA 的载荷加密，由专用宿主解密、校验并启动，保留原有 CLR 元数据与 IL 结构。

**产品构成：界面、引擎、运行时与服务协同工作**

- **可视化客户端**：采用 C# 与 WinUI 3，提供项目配置、目标信息、保护区域编辑、深浅色主题、构建进度和日志展示。
- **原生保护引擎**：以 C++ 实现 PE 分析、区段打包、导入处理、虚拟指令转换和输出构建，承接客户端生成的保护计划。
- **保护运行时**：包含 x86/x64 加载器、x64 虚拟指令解释器和 .NET 专用启动宿主，在目标程序运行时完成对应的恢复、执行与校验。
- **SDK 与项目管理**：通过 SDK 标记关键代码区域，保存项目配置、区域规则和构建快照，让保护配置能够复用、核查与追溯。
- **官网与分发服务**：提供客户端下载、更新日志和后台发布入口，无需账户即可获取安装包，与本地客户端共同构成产品使用流程。

**设计理念：关键逻辑按需保护，配置效果清晰可见**

NovaProtect 围绕三个原则设计。

第一，**保护对象明确**。开发者通过 SDK 标记需要重点处理的代码区域，再依据业务价值、性能要求和兼容性选择保护方式。

第二，**配置效果透明**。构建前展示请求项、生效项、跳过项和冲突原因，帮助开发者理解每项配置在当前目标上的实际作用。

第三，**保护过程可追溯**。项目文件与构建快照记录区域来源、配置和处理结果，方便持续维护软件版本，并在出现兼容性问题时定位原因。

产品提供兼容、均衡、高强度和 Ultra 等预设，帮助开发者在保护需求、运行开销与兼容性之间选择适合当前项目的组合。

**设计参考：借鉴 VMProtect 与 Themida 的产品组织思路**

NovaProtect 的设计参考主要来自 VMProtect Professional 与 Themida。

在 VMProtect Professional 方面，主要借鉴项目、文件与代码区域的组织方式，以及属性配置、构建日志和保护模式的表达思路。在 Themida 方面，主要借鉴通过 SDK 宏标记关键区域，以及将不同保护能力组织为可配置模块的思路。

NovaProtect 将这些参考融入自身的 Windows 工作台、SDK 区域管理和构建计划体系，形成以目标能力为依据、以实际生效结果为中心的操作流程。上述参考描述的是设计方向，不代表复现了相关产品的全部功能、内部算法或保护强度。

**适用范围**

当前原生区段保护覆盖受支持的 x86/x64 EXE；SDK 区域 VM、VM 前置变异与运行时许可、机器绑定主要面向原生 x64。C#/VB .NET EXE 采用加密封装，目前不提供 IL 虚拟化；ARM64 当前用于识别与能力提示，暂不生成保护输出。实际支持情况以客户端构建计划为准。

**简短宣传版**

NovaProtect，面向 Windows 开发者的代码保护工作台。结合区段保护、x64 关键区域虚拟化、字节码加密、导入保护与运行时校验，支持多种工具链生成的 EXE，并为 .NET 程序提供加密封装。通过可视化配置、真实 SDK 区域管理和可追溯构建记录，让关键代码保护更清晰，让软件发布更有序。
